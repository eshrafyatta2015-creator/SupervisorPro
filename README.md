# نظام إدارة البرامج الأسبوعية للمشرفين
### دولة فلسطين - مديرية التربية والتعليم يطا
### قسم الإشراف والتأهيل التربوي

نظام ويب إداري متكامل ومصمم بالكامل باللغة العربية لدعم وتسهيل إعداد ومتابعة وتدقيق واعتماد البرامج والخطط الأسبوعية للمشرفين التربويين في مديرية يطا.

---

## 🏛️ الهوية الرسمية للنظام
- **الجهة المسؤولة**: مديرية التربية والتعليم يطا - قسم الإشراف والتأهيل التربوي.
- **التوقيت الزمني المعتمد**: توقيت القدس وفلسطين (`Asia/Hebron`).
- **صيغة التواريخ**: `dd/MM/yyyy` و `HH:mm`.

---

## 🚀 المميزات والوظائف الأساسية
1. **نظام صلاحيات وأدوار متقدم (RBAC)**:
   - دور **مسؤول النظام (Administrator)**: متابعة كافة المشرفين، إدارة المدارس، الأنشطة، الأسابيع، الاعتماد، التقارير، سجل العمليات، وإعدادات النظام.
   - دور **المشرف التربوي (Supervisor)**: خصوصية تامة؛ لا يرى سوى برنامجه الأسبوعي الخاص به، وتعديل الأنشطة قبل انتهاء المهلة.
2. **التحكم المركزي في الإرسال والمهل**:
   - فتح وإغلاق فترات استقبال البرامج الأسبوعية بتوقيت دقيق.
   - عداد تنازلي لحظي يوضح الوقت المتبقي للمشرفين.
   - منع التعديل تلقائياً بمجرد إغلاق الأسبوع أو بعد الاعتماد.
3. **جدول الأنشطة الأسبوعي الذكي**:
   - التحقق الفوري من صحة البيانات (وقت النهاية بعد البداية، منع تداخل الأنشطة في نفس اليوم، التحقق من وقوع التاريخ داخل نطاق الأسبوع، التحقق من فاعلية المدرسة والنشاط).
   - إمكانية **نسخ برنامج الأسبوع السابق** بضغطة زر واحدة لتسهيل إعداد الخطة كمسودة.
4. **دورة المراجعة والاعتماد الرسمية**:
   - اعتماد البرامج بضغطة زر.
   - طلب تعديل مسبب مع تسجيل ملاحظة إدارية إجبارية (مثال: «يرجى تعديل برنامج يوم الثلاثاء...»).
   - إشعار فوري للمشرف وإعادة فتح البرنامج للتعديل وإعادة الإرسال.
5. **لوحة معلومات ورسوم بيانية (Dashboard)**:
   - نسبة الإرسال الإجمالية، البرامج حسب الحالة، توزيع الأيام، والأنشطة الأكثر تكراراً.
6. **تقرير خاص: "المشرفون الذين لم يرسلوا"**:
   - متابعة المشرفين المتأخرين وإرسال تنبيهات فردية أو جماعية فورية.
7. **10 تقارير شاملة قابلة للتصدير**:
   - تصدير فوري إلى **Excel (CSV بترميز UTF-8 مع BOM)**.
   - طباعة رسمية بنسق PDF وترويسة وزارة التربية والتعليم ومديرية يطا.
8. **سجل العمليات والتدقيق الأمني (Audit Logs)**:
   - تسجيل كل حركة (تسجيل دخول، إرسال، اعتماد، تعديل، إلخ) مع التاريخ والوقت وعنوان IP.
9. **النسخ الاحتياطي واستعادة البيانات**:
   - تصدير واسترجاع نسخة احتياطية كاملة بصيغة JSON.
   - ملف `Database.sql` جاهز للتنفيذ على Microsoft SQL Server / SQL Server Express.

---

## 🛠️ التقنيات المستخدمة
- **الواجهة الأمامية التفاعلية (Live Web App)**: React 19 + TypeScript + Tailwind CSS (RTL عربي بالكامل).
- **الخادم وقاعدة البيانات في الإنتاج (ASP.NET Core Solution)**:
  - C# .NET 10 / .NET 8
  - Entity Framework Core 8
  - Microsoft SQL Server / SQL Server Express
  - Cookie Authentication & Claims-based Authorization
  - BCrypt Password Hashing
